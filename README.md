# Тінь над містом (Noir Rush)

Нуарний 3D-ранер у браузері: детектив у плащі й капелюсі біжить нічним містом.

Грати: https://pavel-kirsanov.github.io/Noir-Rush/

- **Сцена**: детектив стежить за курсором, клік запускає трос, а якщо затиснути й відпустити — він б’є.
- **Погоня**: три смуги, стрибки й підкати, барикади й машини, капелюхи замість монет.
- 15 рівнів і 5 районів; кожні 3 рівні відкривають нову здібність (на пробілі).
- Персонажі, бустери, крамниця капелюхів, щоденні завдання, рекорди (у `localStorage`).
- Музика й звуки синтезуються через Web Audio.

## Запуск

Гра — це один файл `index.html`, збирати нічого не потрібно. Підійде будь-який статичний сервер:

```bash
python3 -m http.server 8000
```

Потім відкрийте http://localhost:8000.

## Будова

- `index.html`: уся гра (розмітка, стилі, скрипт).
- `vendor/three.min.js`: Three.js r128 (MIT, див. `vendor/three.LICENSE`).
- Шрифти Oswald, PT Serif і PT Mono підключаються з Google Fonts; без мережі використовуються запасні шрифти.

## Керування

| Дія | Клавіатура | Телефон |
|---|---|---|
| Змінити смугу | ← → / A D | свайп вліво/вправо |
| Стрибок | ↑ / W | свайп угору, тап |
| Підкат | ↓ / S | свайп униз |
| Здібність | Пробіл | кругла кнопка |
| Пауза | Esc / P | кнопка «Пауза» |
