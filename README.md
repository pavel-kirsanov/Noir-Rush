# Тень над городом (Noir Rush)

Нуарный 3D-раннер в браузере: детектив в плаще и шляпе бежит по ночному городу.

- **Сцена**: детектив следит за курсором, клик запускает трос, а если зажать и отпустить, он бьёт.
- **Погоня**: три полосы, прыжки и подкаты, баррикады и машины, вместо монет шляпы.
- 15 уровней и 5 районов; каждые 3 уровня открывают новую способность (на пробел).
- Персонажи, бустеры, магазин шляп, ежедневные задания, рекорды (в `localStorage`).
- Музыка и звуки синтезируются через Web Audio.

## Запуск

Игра состоит из одного файла `index.html` и не требует сборки. Нужен любой статический сервер:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Устройство

- `index.html`: вся игра (разметка, стили, скрипт).
- `vendor/three.min.js`: Three.js r128 (MIT, см. `vendor/three.LICENSE`).
- Шрифты Oswald, PT Serif и PT Mono подключаются с Google Fonts; без сети используются запасные шрифты.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Сменить полосу | ← → / A D | свайп влево/вправо |
| Прыжок | ↑ / W | свайп вверх, тап |
| Подкат | ↓ / S | свайп вниз |
| Способность | Пробел | круглая кнопка |
| Пауза | Esc | кнопка «Пауза» |
